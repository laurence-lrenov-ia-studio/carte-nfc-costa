Avant de plonger dans les visuels

Tout ce que vous allez voir dans cette présentation est une proposition de visuels — du support physique de la carte au design de la page web qui s'ouvre quand on flash le QR code.

L'objectif est de vous montrer tout ce qu'on peut faire ensemble : les matières, les finitions, les ambiances graphiques. Rien n'est figé. Couleurs, polices, formats, contenus, libellés — chaque détail sera validé avec vous avant production.

Les pages web Linktree ci-dessous sont vivantes et interactives : scrollez à l'intérieur pour les explorer.

Le principe

Une carte qui connecte

Le QR code imprimé ou gravé sur chaque carte ouvre une page de liens à votre nom (interface type Linktree). Un scan suffit à votre interlocuteur pour accéder à tout.

Carte de contact

Vos coordonnées s'enregistrent dans le téléphone, sans saisie manuelle.

WhatsApp direct

Un clic et la conversation démarre, sans copier votre numéro.

Demande de devis

Bouton dédié qui ouvre un email pré-rempli vers votre adresse pro.

Vos réalisations

Châteaux viticoles, piscines, tomettes, marbre — vos chantiers en photos.
